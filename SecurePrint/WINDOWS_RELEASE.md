# SecurePrint Shop - Windows Release Documentation

## Application Identity
- **Application Name**: SecurePrint Shop
- **Version**: 1.0.0
- **Desktop Framework**: Flutter (Windows Desktop)

## Production Build Instructions

### Prerequisites
To build the application from source on a developer machine, the following prerequisites are required:
1. Flutter SDK (3.47.2 or compatible `3.13.2` channel)
2. Visual Studio Community with "Desktop development with C++" workload
3. **Windows Developer Mode Enabled**: Flutter strictly requires Windows Developer Mode to be active to generate plugin symlinks without requiring Admin elevation. If Developer Mode is disabled, the build command will fail with `Building with plugins requires symlink support. Please enable Developer Mode in your system settings.`

### Build Command
Navigate to `SecurePrint/shop_desktop` and execute:
```powershell
flutter build windows --release
```

### Output Directory
The release artifacts will be generated in:
```
build/windows/x64/runner/Release/
```

### Executable Name
```
SecurePrint-Shop.exe
```

### Required Runtime Files
The final distribution folder must contain the executable and its adjacent runtime dependencies (generated by the build):
- `SecurePrint-Shop.exe`
- `flutter_windows.dll`
- `data/` directory (contains ICU data and asset bundles)
- Supporting native plugin `.dll` files (e.g., `printing_plugin.dll`)

*Note: These files must be packaged together. `SecurePrint-Shop.exe` is not a standalone portable executable and will fail to launch if separated from `flutter_windows.dll` and `data/`.*

## Configuration Process
The application securely stores settings in native Windows `SecureStorage`. 

### Backend URL Configuration
By default, the application is shipped targeting `Environment.production`, which maps to `https://api.secureprint.com`.
Shop owners can override this by navigating to the internal **Settings -> Configuration** page and overriding the **Backend URL** field. 

## Testing Performed
- Unit and Widget Testing: Executed flawlessly natively via `flutter test` (47/47 specs passed).
- Security Validations: M13 finalized without critical regression.
- **Production Build Blocked**: The localized Windows environment on this agent's terminal lacked "Developer Mode", causing `flutter build windows --release` to halt on the symlink restriction. The execution and clean-machine run of the raw `.exe` were deferred.

## Known Windows Security / SmartScreen Warnings
As this is an unsigned executable (Code Signing is reserved for M15/M16 packaging), Windows Defender and SmartScreen will universally flag the `.exe` as "Unknown Publisher" upon execution or download. Users must manually bypass via "More info" -> "Run anyway" until a valid Authenticode certificate is applied to the installer payload.

## Known Limitations
- The underlying `directPrintPdf` bindings bypass native Windows UI spooler popups, making printing exceptionally fast, but removes localized printer manipulation.
- Building the `.exe` natively requires Windows Developer Mode enabled.
